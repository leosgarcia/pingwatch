## 🎯 Sobre o Projeto

O **PingWatch** é uma solução avançada para diagnóstico e monitoramento de rede por linha de comando. Inspirado originalmente no projeto [Nping de hanshuaikang](https://github.com/hanshuaikang/Nping), esta evolução foca em performance paralela, extensibilidade e uma experiência de usuário (CLI) refinada.

## 🚀 Funcionalidades Principais

- **Ping Paralelo:** Dispare requisições concorrentes sem gargalos.
- **Estatísticas de Latência:** Relatórios agregados precisos de tempo de resposta.
- **Interface Moderna:** Saídas ricas e legíveis no terminal.
- **Arquitetura Extensível:** Pronta para receber suporte a UI gráfica e agentes distribuídos.

## 📦 Como Usar

```bash
git clone https://github.com/leosgarcia/pingwatch.git
cd pingwatch
# Execute a ferramenta (substitua pelo ponto de entrada correto)
python main.py
```
